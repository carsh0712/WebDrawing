기능 명세

MVP에서 웹 드로잉 앱으로 동작하기 위해 필요한 기본 기능을 정리한다.

1. 캔버스 기능

새 캔버스기본 캔버스를 생성하고 기존 작업이 있을 경우 초기화 확인을 표시한다.
캔버스 크기MVP는 기본 크기를 제공하고, 이후 사용자 지정 크기를 확장한다.
확대/축소작업 영역에서 캔버스를 확대하거나 축소해 세부 작업을 확인한다.
이동확대 상태에서 캔버스 위치를 이동해 원하는 영역을 볼 수 있게 한다.

2. 드로잉 도구

선택 도구업로드 이미지 또는 캔버스 요소를 선택하는 기본 도구로 사용한다.
펜마우스 또는 터치 입력으로 단단하고 선명한 자유 곡선을 그린다.
수묵화 브러시색상, 굵기, 투명도를 조절해 먹 번짐, 농담, 마른 붓 결이 섞인 선을 그린다.
지우개그려진 내용을 지우며, 지우개 크기를 조절할 수 있게 한다.
채우기MVP에서는 단순 배경 채우기 또는 선택 색상 적용 수준으로 검토한다.
텍스트간단한 설명 문구를 캔버스에 추가할 수 있게 한다.
이미지 삽입업로드된 이미지를 캔버스에 배치한다.

3. 편집 기능

  • 실행 취소 및 다시 실행
  • 전체 지우기
  • 현재 도구 상태 표시
  • 색상 팔레트 및 사용자 지정 색상
  • 수묵화 브러시 굵기 및 투명도 조절
  • PNG 다운로드

4. MVP 제외 범위

  • 회원가입 및 로그인
  • 서버 기반 계정 저장
  • 실시간 공동 편집
  • 고급 레이어 관리
  • 필압, 블렌딩 모드, 다중 브러시 프리셋
  • 복잡한 벡터 편집 및 도형 편집
