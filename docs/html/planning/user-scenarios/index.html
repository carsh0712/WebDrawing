기획서 목차로 돌아가기

사용자 및 시나리오

정식 서비스는 회원가입한 모든 유저를 대상으로 하지만, MVP에서는 로그인 없이 사용할 수 있는 공개형 드로잉 흐름으로 시작한다.

1. 대상 사용자

정식 서비스 회원가입한 모든 유저. 개인 작업물 저장, 업로드 이미지 관리, 공유 기능을 계정 기반으로 사용할 수 있는 사용자를 대상으로 한다.
MVP 사용자 로그인 없이 웹페이지에 접속해 바로 그림을 그리고, 이미지를 업로드해 확인하고, 작업물을 로컬에 저장하려는 사용자.
주요 니즈 빠르게 그리기, 이미지 위에 표시하기, 간단한 편집, 작업 저장, 저장한 그림 다시 보기.

2. 대표 사용 시나리오

  1. 사용자가 WebDrawingCanvas에 접속한다.
  2. 로그인 절차 없이 포토샵형 작업 화면으로 진입한다.
  3. 새 캔버스에서 펜, 브러시, 지우개를 사용해 그림을 그린다.
  4. 필요하면 로컬 이미지를 업로드하고 업로드 목록에서 이미지를 확인한다.
  5. 업로드 이미지를 캔버스에 배치하거나 참고 이미지로 보면서 그림을 수정한다.
  6. 작업물을 브라우저에 저장하고 저장 목록에서 다시 확인한다.
  7. 완성된 결과를 PNG 파일로 다운로드한다.

3. 정식 서비스 확장 시나리오

  • 회원가입 후 여러 기기에서 저장된 작업을 불러온다.
  • 업로드한 그림과 저장한 작업물을 계정별 라이브러리에서 관리한다.
  • 작업물을 링크로 공유하거나 읽기 전용으로 공개한다.
  • 다른 사용자가 공유받은 그림을 확인하거나 복사본으로 편집한다.
