WebDrawingCanvas 기획서 - 개요

이 문서는 WebDrawingCanvas의 서비스 개요와 MVP 방향을 정리하는 세부 기획서다. 서비스는 최종적으로 회원가입한 모든 유저를 대상으로 제공하되, MVP에서는 로그인 없이 사용할 수 있는 웹 드로잉 경험을 먼저 검증한다.

1. 서비스 개요

서비스명 WebDrawingCanvas
서비스 목적 웹브라우저에서 그림을 그리고, 작업물을 저장하고, 업로드한 그림을 다시 확인하며, 다른 사람에게 쉽게 공유할 수 있게 한다.
핵심 사용자 정식 서비스에서는 회원가입한 모든 유저를 대상으로 한다. MVP에서는 로그인 없이 접속한 사용자가 바로 드로잉 기능을 사용할 수 있게 한다.
핵심 가치 빠른 접근성, 포토샵형 작업 화면의 익숙함, 기본 드로잉 도구, 작업 저장, 업로드 이미지 확인
MVP 원칙 로그인, 서버 계정, 실시간 협업보다 캔버스 편집, 이미지 업로드, 저장, 다시 보기의 핵심 흐름을 우선한다.

3. 확정된 기획 방향

사용자 정책 정식 서비스는 회원가입한 모든 유저를 대상으로 한다.
MVP 접근 방식 MVP에서는 로그인 없이 바로 접속해 그림을 그리고 저장할 수 있게 한다.
화면 방향 포토샵처럼 상단 메뉴, 좌측 도구 바, 중앙 캔버스, 우측 속성/목록 패널을 가진 작업형 화면으로 구성한다.
저장 방향 MVP에서는 브라우저 로컬 저장과 이미지 파일 다운로드를 우선한다.
업로드 이미지 사용자가 업로드한 그림을 목록 또는 패널에서 확인하고, 선택한 이미지를 다시 볼 수 있게 한다.

5. MVP 기획안

MVP는 별도 설치나 로그인 없이 웹페이지에 접속해 바로 그림을 그리고, 이미지를 업로드해 확인하거나 캔버스에 배치하며, 결과물을 브라우저에 저장하거나 이미지 파일로 내보낼 수 있는 수준을 1차 목표로 한다.

5.1 MVP 목표

목표 사용자 회원가입 기반 정식 서비스의 전체 사용자를 염두에 두되, MVP에서는 로그인 없이 간단한 스케치와 이미지 편집을 해보고 싶은 사용자
사용 환경 데스크톱 브라우저를 우선 지원하고, 모바일과 태블릿은 기본 터치 입력이 가능한 수준까지 검토한다.
핵심 경험 접속 후 포토샵형 작업 화면이 열리고, 도구 선택, 그리기, 업로드 이미지 보기, 저장, 다운로드까지 한 화면에서 완료한다.
저장 방향 초기 버전은 브라우저 로컬 저장, 저장 목록 보기, PNG 다운로드를 우선한다.
업로드 방향 사용자가 업로드한 그림을 목록에서 확인하고, 선택한 이미지를 캔버스 작업 대상으로 사용할 수 있게 한다.

5.2 기본 화면 구성

  • 상단 메뉴 바: 새 파일, 열기, 저장, 다운로드, 실행 취소, 다시 실행을 배치한다.
  • 좌측 도구 바: 선택, 이동, 펜, 브러시, 지우개, 채우기, 텍스트, 이미지 삽입 도구를 배치한다.
  • 중앙 작업 영역: 회색 작업 배경 위에 캔버스를 배치해 포토샵과 유사한 편집감을 제공한다.
  • 우측 패널: 색상, 브러시 속성, 캔버스 정보, 업로드 이미지 목록, 저장 목록을 표시한다.
  • 하단 상태 바: 저장 상태, 확대 비율, 캔버스 크기, 현재 도구 정보를 간단히 표시한다.
  • 확인 모달: 새 캔버스 생성이나 초기화처럼 기존 작업이 사라질 수 있는 동작을 확인한다.

5.3 핵심 기능 명세

캔버스 기본 크기의 흰색 캔버스를 제공하고, 새 캔버스 생성 시 현재 작업을 초기화한다.
펜 도구 마우스 또는 포인터 입력으로 단단하고 선명한 자유 곡선을 그린다. 색상, 선 굵기, 투명도를 적용한다.
지우개 선 굵기 설정을 공유하거나 별도 크기를 사용해 그려진 내용을 지운다.
수묵화 브러시 색상, 굵기, 투명도를 조절하며 먹 번짐, 농담, 마른 붓 가장자리가 섞인 표현을 제공한다. 현재 설정은 우측 패널에서 확인한다.
색상 선택 기본 색상 팔레트와 사용자 지정 색상 선택을 제공한다.
선 굵기 얇은 선부터 굵은 선까지 단계적으로 조절한다.
실행 취소/다시 실행 사용자의 최근 그리기 동작을 되돌리거나 다시 적용한다.
이미지 업로드 사용자의 로컬 이미지 파일을 업로드하고 업로드 목록에서 썸네일로 확인한다.
업로드 이미지 보기 업로드된 그림을 선택하면 미리보기 또는 캔버스 배치 대상으로 확인할 수 있게 한다.
로컬 저장 브라우저 저장소에 현재 작업을 저장하고, 페이지 재진입 시 불러올 수 있게 한다.
저장 목록 저장된 작업의 이름, 저장 시각, 미리보기를 표시하고 선택한 작업을 불러온다.
이미지 다운로드 현재 캔버스를 PNG 파일로 저장한다.

5.4 사용자 흐름

  1. 사용자가 WebDrawingCanvas 페이지에 접속한다.
  2. 포토샵형 작업 화면과 기본 캔버스가 표시된다.
  3. 사용자가 펜 색상과 선 굵기를 선택한다.
  4. 캔버스 위에 그림을 그린다.
  5. 필요하면 이미지를 업로드하고, 업로드 목록에서 그림을 확인한 뒤 캔버스 작업에 사용한다.
  6. 지우개, 실행 취소, 다시 실행을 사용해 작업을 수정한다.
  7. 작업이 끝나면 브라우저에 저장하고 저장 목록에서 다시 확인한다.
  8. 필요하면 PNG 파일로 다운로드한다.
  9. 공유가 필요하면 다운로드한 이미지 파일을 외부 채널로 전달한다.

5.5 MVP 제외 범위

  • 회원가입 및 로그인
  • 서버 기반 프로젝트 저장
  • 공유 링크 생성
  • 실시간 공동 편집
  • 고급 레이어 관리
  • 정교한 도형 편집
  • 고급 브러시, 필압, 블렌딩 모드

5.6 MVP 성공 기준

  • 사용자가 첫 화면에서 별도 안내 없이 그림을 시작할 수 있다.
  • 포토샵과 유사한 기본 화면 구조 안에서 주요 도구를 찾을 수 있다.
  • 펜, 브러시, 지우개, 색상, 굵기, 실행 취소/다시 실행이 안정적으로 동작한다.
  • 업로드한 이미지를 목록에서 확인하고 캔버스 작업에 사용할 수 있다.
  • 새로고침 또는 재방문 후에도 저장된 작업을 불러올 수 있다.
  • PNG 다운로드 결과물이 실제 캔버스 내용과 일치한다.
  • 데스크톱 주요 브라우저에서 기본 사용 흐름이 깨지지 않는다.
초기 MVP 방향 로그인 없이 시작해 캔버스 사용성, 업로드 이미지 확인, 저장 안정성을 먼저 확인한 뒤, 회원 계정 기반 저장과 링크 공유를 후속 단계에서 검토한다.
