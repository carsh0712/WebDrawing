화면 구성

MVP 화면은 포토샵과 유사한 작업형 구조를 따른다. 사용자는 중앙 캔버스를 기준으로 좌측 도구와 우측 패널을 사용한다.

1. 전체 레이아웃

상단 메뉴 바새 파일, 열기, 저장, 다운로드, 실행 취소, 다시 실행, 확대/축소 기능을 제공한다.
좌측 도구 바선택, 이동, 펜, 브러시, 지우개, 채우기, 텍스트, 이미지 삽입 도구를 세로로 배치한다.
중앙 작업 영역회색 작업 배경 위에 흰색 캔버스를 표시해 편집 대상이 명확히 보이도록 한다.
우측 속성 패널색상, 브러시 속성, 캔버스 정보, 업로드 이미지 목록, 저장 목록을 탭 또는 섹션으로 제공한다.
하단 상태 바저장 상태, 확대 비율, 캔버스 크기, 현재 도구명을 표시한다.

2. 우측 패널 구성

  • 속성: 현재 선택된 도구의 색상, 굵기, 투명도, 지우개 크기 등을 조절한다.
  • 업로드 이미지: 업로드한 그림의 썸네일 목록을 보여주고 선택 시 미리보기 또는 캔버스 배치를 지원한다.
  • 저장 목록: 브라우저에 저장된 작업의 썸네일, 이름, 저장 시각을 보여준다.
  • 캔버스 정보: 캔버스 크기, 배경색, 확대 비율을 확인한다.

3. 화면 사용 원칙

  • 사용자가 첫 화면에서 바로 캔버스와 도구를 인지할 수 있어야 한다.
  • 드로잉 도구는 좌측에 고정해 반복 작업 중 위치가 바뀌지 않게 한다.
  • 저장과 업로드 이미지 확인은 우측 패널에서 즉시 접근할 수 있게 한다.
  • 작업 중 캔버스가 가장 큰 시각적 비중을 가진다.
