이 페이지는 기획서의 세부 문서 링크를 관리하는 목차 페이지다. 실제 기획 내용은 아래 세부 페이지에서 주제별로 나누어 작성한다.

세부 기획서

개요 서비스 목적, 사용자 범위, MVP 방향을 정리한다. 작성 완료 사용자 및 시나리오 회원가입 대상 서비스와 MVP 비로그인 사용 흐름을 정리한다. 작성 완료 기능 명세 웹 드로잉에 필요한 기본 기능과 MVP 제외 범위를 정리한다. 작성 완료 화면 구성 포토샵과 유사한 작업 화면 구조를 기준으로 정리한다. 작성 완료 저장 및 업로드 이미지 저장, 불러오기, 업로드된 그림 보기, 내보내기 범위를 정리한다. 작성 완료 확장 계획 로그인, 서버 저장, 레이어, 실시간 협업 등 후속 범위를 정리한다. 예정
