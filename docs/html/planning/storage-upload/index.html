저장 및 업로드 이미지

MVP에서는 로그인 없이도 현재 브라우저에서 작업물을 저장하고, 업로드한 그림을 목록에서 확인할 수 있게 한다.

1. 저장 기능

로컬 저장현재 캔버스 상태를 브라우저 저장소에 저장한다.
저장 목록저장한 작업의 이름, 저장 시각, 썸네일을 우측 패널에 표시한다.
불러오기저장 목록에서 작업을 선택하면 캔버스에 해당 작업을 복원한다.
덮어쓰기현재 작업을 같은 이름으로 다시 저장할 수 있게 한다.
삭제저장된 작업을 목록에서 삭제할 수 있게 한다.

2. 업로드 이미지 보기

이미지 업로드사용자가 로컬의 PNG, JPG, JPEG, WebP 이미지를 업로드한다.
업로드 목록업로드한 이미지를 썸네일 목록으로 보여준다.
이미지 미리보기목록에서 이미지를 선택하면 우측 패널 또는 작업 영역에서 크게 확인한다.
캔버스 배치선택한 업로드 이미지를 캔버스에 배치해 그 위에 드로잉할 수 있게 한다.
업로드 기록MVP에서는 현재 브라우저 기준으로 업로드 이미지 정보를 유지한다.

3. 다운로드 및 공유

  • 현재 캔버스를 PNG 파일로 다운로드한다.
  • MVP의 공유는 다운로드한 이미지 파일을 외부 채널로 전달하는 방식으로 본다.
  • 링크 공유, 공개 범위 설정, 회원별 공유 권한은 정식 서비스 확장 범위로 둔다.

4. 저장 데이터 기준

  1. 작업 이름
  2. 저장 시각
  3. 캔버스 크기
  4. 캔버스 이미지 또는 재편집 가능한 작업 데이터
  5. 썸네일 이미지
  6. 사용한 업로드 이미지 참조 정보
