프로젝트 개요

프로젝트명 WebDrawingCanvas
목표 브라우저에서 바로 그림을 그리고, 저장과 공유까지 이어지는 간단하고 명확한 드로잉 작업 흐름을 제공한다.
문서 방향 기획서는 논의 후 세부 문서로 확장하고, 개발 계획서는 확정된 기획을 바탕으로 단계별 실행 계획을 채운다.
기획서 서비스 목적, 사용자, 기능 범위, 화면 흐름, 저장 및 공유 정책을 정리한다. 기획서로 이동 개발 계획서 기획서를 바탕으로 구현 단계, 기술 검토 항목, 산출물과 일정의 뼈대를 관리한다. 개발 계획서로 이동
