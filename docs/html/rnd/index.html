WebDrawingCanvas R&D

이 문서는 WebDrawingCanvas 확장 개발에 필요한 기술 조사 내용을 관리한다. 초보자도 흐름을 이해할 수 있도록 개념, 선택 이유, 적용 방법, 주의점을 함께 정리한다.

기술 조사 항목

Supabase Next.js 서버에서 Supabase PostgreSQL, Auth, Storage를 연결해 서버 저장과 사용자별 데이터 권한을 구현하는 기준을 정리한다. 작성 완료 Vercel + Next.js Next.js 백엔드 프로젝트를 Vercel에 연결하고 Preview/Production 배포, 환경 변수, Supabase 연결을 검증하는 기준을 정리한다. 작성 완료
