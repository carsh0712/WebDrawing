6단계. 이미지 업로드 및 업로드 목록 구현

완료 사용자가 업로드한 그림을 우측 패널에서 볼 수 있게 했다.

목표

로컬 이미지 파일을 앱에 가져오고, 업로드된 그림을 썸네일 목록과 미리보기로 확인한다.

구현 방향

지원 형식PNG, JPG, JPEG, WebP를 우선 지원한다.
업로드 방식파일 선택 버튼과 드래그 앤 드롭을 검토한다.
목록 표시우측 패널에 썸네일, 파일명, 크기 정보를 표시한다.
미리보기목록 선택 시 더 큰 이미지로 확인할 수 있게 한다.

주요 작업

  1. 파일 입력 UI를 만들었다.
  2. 파일 타입과 크기를 검증했다.
  3. Object URL로 미리보기 데이터를 만들었다.
  4. 업로드 이미지 배열과 선택 상태를 관리했다.

완료 기준

  • 업로드한 이미지가 목록에 나타난다.
  • 선택한 이미지를 미리보기로 확인할 수 있다.
  • 지원하지 않는 파일은 명확히 거절된다.
