5단계. 편집 이력 기능 구현

완료 실행 취소, 다시 실행, 초기화 같은 편집 안정장치를 만들었다.

목표

사용자가 실수해도 작업을 되돌릴 수 있게 하고, 파괴적인 작업에는 확인 절차를 둔다.

구현 방향

이력 단위한 번의 드로잉 스트로크, 이미지 배치, 전체 지우기를 작업 단위로 기록한다.
Undo이전 캔버스 상태로 되돌린다.
Redo되돌린 상태를 다시 적용한다.
초기화새 캔버스와 전체 지우기는 확인 모달을 거친다.

주요 작업

  1. 이력 스택과 다시 실행 스택을 만들었다.
  2. 작업 완료 시 캔버스 상태를 저장했다.
  3. Undo/Redo 버튼 활성 상태를 관리했다.
  4. 초기화 확인 모달과 변경 상태 표시를 구현했다.

완료 기준

  • 최근 작업을 순서대로 되돌릴 수 있다.
  • 되돌린 작업을 다시 적용할 수 있다.
  • 초기화 시 사용자가 작업 손실을 인지할 수 있다.
