WebDrawingCanvas 개발 계획서

이 문서는 WebDrawingCanvas MVP를 단계별로 개발하기 위한 실행 계획서다. 먼저 React + Vite + TypeScript로 프론트엔드 드로잉 MVP를 완성하고, 이후 Next.js 백엔드를 개발해 Supabase DB와 Vercel 배포 환경을 연결한다.

기획 작성 완료 개발 계획 작성 완료 프론트엔드 MVP 완료 백엔드 확장 진행 중

1. 개발 계획 기준

기획 기준 정식 서비스는 회원가입 유저 대상이지만, MVP는 로그인 없이 사용할 수 있는 웹 드로잉 앱으로 개발한다.
프론트엔드 기준 React + Vite + TypeScript로 먼저 개발한다. 캔버스, 드로잉 도구, 업로드 보기, 로컬 저장, PNG 다운로드까지 프론트엔드 MVP로 완성한다.
백엔드 기준 프론트엔드 MVP 이후 Next.js 프레임워크로 백엔드를 개발한다. 인증, 서버 저장, Supabase 연동, 공유 링크 API를 담당한다.
화면 기준 포토샵처럼 상단 메뉴 바, 좌측 도구 바, 중앙 캔버스, 우측 속성/업로드/저장 패널, 하단 상태 바를 가진다.
핵심 기능 펜, 브러시, 지우개, 색상, 굵기, 투명도, 실행 취소/다시 실행, 이미지 업로드, 업로드 이미지 보기, 로컬 저장, 저장 목록, PNG 다운로드.
우선순위 프론트엔드 MVP 완성, 프론트엔드 검증, Next.js 백엔드 생성, Supabase DB/Storage 연결, Vercel 배포 순서로 진행한다.

2. 10단계 개발 계획

1단계

React + Vite + TypeScript 프론트엔드 구조 생성

완료

React + Vite + TypeScript 기반으로 프론트엔드 앱 구조를 만들었다.

주요 작업

Vite 프로젝트, TypeScript 설정, React 컴포넌트 구조, 스타일 파일, 에셋 폴더, 문서 링크 정리 완료.

완료 기준

Vite 개발 서버에서 React 앱이 정상 실행되고 기본 레이아웃을 표시할 준비가 되었다.
2단계

포토샵형 화면 레이아웃 구현

완료

상단 메뉴 바, 좌측 도구 바, 중앙 작업 영역, 우측 패널, 하단 상태 바를 배치했다.

주요 작업

반응형 레이아웃, 고정 도구 바, 우측 탭 패널, 중앙 캔버스 래퍼, 상태 표시 영역 구현 완료.

완료 기준

사용자가 첫 화면에서 캔버스와 주요 도구 위치를 바로 인지할 수 있다.
3단계

캔버스 엔진 및 포인터 입력 구현

완료

HTML Canvas 기반의 그리기 영역을 만들고 마우스, 펜, 터치 입력을 처리했다.

주요 작업

캔버스 초기화, 좌표 계산, 포인터 다운/이동/업 이벤트, 화면 배율 보정, 기본 배경 처리 완료.

완료 기준

사용자가 캔버스 위에 끊김 없이 기본 선을 그릴 수 있다.
4단계

기본 드로잉 도구 구현

완료

펜, 수묵화 브러시, 지우개, 색상, 굵기, 투명도 조절 기능을 구현했다.

주요 작업

도구 선택 상태, 수묵화 브러시 옵션, 색상 팔레트, 커스텀 색상, 지우개 모드, 현재 도구 표시 완료.

완료 기준

좌측 도구와 우측 속성 패널을 통해 기본 드로잉 작업을 수행할 수 있다.
5단계

편집 이력 기능 구현

완료

실행 취소, 다시 실행, 전체 지우기, 새 캔버스 확인 흐름을 구현했다.

주요 작업

캔버스 상태 스냅샷, undo/redo 스택, 초기화 확인 모달, 작업 변경 상태 추적 완료.

완료 기준

사용자의 최근 작업을 안정적으로 되돌리고 다시 적용할 수 있다.
6단계

이미지 업로드 및 업로드 목록 구현

완료

사용자가 로컬 이미지를 업로드하고 우측 패널에서 업로드된 그림을 볼 수 있게 했다.

주요 작업

파일 선택, 이미지 타입 검증, 썸네일 생성, 업로드 목록 표시, 선택 이미지 미리보기 완료.

완료 기준

업로드한 이미지가 목록에 표시되고 선택한 이미지를 확인할 수 있다.
7단계

업로드 이미지 캔버스 배치 구현

완료

업로드 목록에서 선택한 이미지를 캔버스에 배치하고 그 위에 드로잉할 수 있게 했다.

주요 작업

이미지 삽입, 위치 지정, 기본 크기 조절, 캔버스 합성, 선택 이미지 배치 상태 반영 완료.

완료 기준

선택한 업로드 이미지가 캔버스에 보이고 사용자가 그 위에 추가 작업을 할 수 있다.

완료

작업물을 브라우저에 저장하고, 저장 목록, 불러오기, 삭제, PNG 다운로드까지 프론트엔드 MVP로 완성했다.

주요 작업

저장 데이터 구조, 저장 이름, 저장 시각, 썸네일, 저장 목록, 불러오기, 삭제, 덮어쓰기, PNG 다운로드 완료.

완료 기준

로그인 없이 저장, 불러오기, 삭제, 다운로드가 모두 동작한다.

프론트엔드 MVP 검증 및 빌드

완료

React + Vite + TypeScript 프론트엔드 MVP를 검증하고 배포 가능한 빌드 산출물을 만들었다.

주요 작업

기능 QA, 타입 체크, 빌드 확인, 반응형 확인, 브라우저 테스트, 문서 상태 갱신 완료.

완료 기준

프론트엔드 MVP가 독립 실행 가능한 상태로 검증된다.

Next.js 백엔드, Supabase, Vercel 확장

진행 중

기존 기타 단계의 Vercel 배포, Supabase DB/Storage 연결, 인증, 서버 저장 확장을 10단계 세부 계획으로 통합했다.

주요 작업

완료: 10-1부터 10-11까지. 다음 진행 예정: 10-12부터 10-14까지 인증, Vercel 배포, 보안 검증.

완료 기준

개발 Docker DB와 운영 Supabase에서 서버 저장, 업로드, 인증, 배포 검증이 모두 동작한다.

3. 개발 상태 배지 기준

대기 아직 구현을 시작하지 않은 단계다.
진행 중 구현 또는 검증이 진행 중인 단계다.
검토 필요 기능 구현은 되었지만 사용자 확인이나 QA가 필요한 단계다.
완료 완료 기준을 충족해 다음 단계의 기반으로 사용할 수 있는 단계다.
1단계부터 9단계까지 완료되었고, 10단계는 기존 기타 단계를 흡수해 진행 중이다. 세부 계획서에서 완료된 준비 작업과 대기 중인 실제 구현 작업을 구분해 관리한다.

4. 기술 검토 항목

  • 프론트엔드 구현 방식: React + Vite + TypeScript로 MVP를 먼저 개발한다.
  • 캔버스 구현 방식: HTML Canvas API를 기본으로 사용한다.
  • 백엔드 구현 방식: 프론트엔드 MVP 이후 Next.js 프레임워크로 API, 인증, 서버 저장 기능을 개발한다.
  • 저장소: 프론트엔드 MVP는 브라우저 로컬 저장소를 사용하고, 서버 저장 확장 시 Supabase Database와 Storage를 사용한다.
  • 이미지 처리: PNG, JPG, JPEG, WebP 업로드와 PNG 다운로드를 우선 지원한다.
  • 정식 서비스 확장: 회원가입, 서버 저장, 링크 공유, 권한 관리는 Supabase 연동 단계에서 구체화한다.
  • 배포 방식: 프론트엔드 MVP 검증 이후 Vercel을 기본 배포 환경으로 사용하고, 환경 변수로 Supabase 접속 정보를 관리한다.
