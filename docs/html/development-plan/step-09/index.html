9단계. 프론트엔드 MVP 검증 및 빌드

완료 React + Vite + TypeScript 프론트엔드 MVP를 검증하고 백엔드 연결 전 기준점을 만들었다.

목표

프론트엔드만으로 동작하는 드로잉 MVP를 안정화하고, 이후 Next.js 백엔드와 붙일 수 있는 인터페이스를 정리한다.

검증 방향

기능 QA그리기, 도구 변경, 이미지 업로드, 저장, 불러오기, PNG 다운로드 흐름을 점검한다.
타입 검증TypeScript 타입 오류를 제거하고 주요 데이터 타입을 정리한다.
빌드 검증Vite production build가 정상 생성되는지 확인한다.
백엔드 대비저장, 업로드, 사용자 작업 목록 로직을 서비스 계층으로 분리해 API 교체가 쉽게 만든다.

주요 작업

  1. 프론트엔드 MVP 사용자 흐름 체크리스트를 작성했다.
  2. TypeScript 타입 오류와 런타임 오류를 정리했다.
  3. 반응형 화면과 브라우저 호환성을 확인했다.
  4. 로컬 저장 서비스와 추후 서버 저장 서비스의 인터페이스를 분리했다.
  5. Vite 빌드 산출물을 확인했다.

검증 결과

그리기펜, 브러시, 지우개, 색상, 굵기, 투명도 상태가 캔버스 렌더링에 연결되어 있다.
편집 이력스트로크와 이미지 배치가 Undo/Redo 스냅샷에 기록된다.
업로드PNG, JPG, JPEG, WebP 업로드, 썸네일 목록, 선택 미리보기, 캔버스 배치가 동작한다.
저장로컬 저장, 덮어쓰기, 불러오기, 삭제, PNG 다운로드를 지원한다.
서비스 분리client/src/services/canvasStorageService.ts와 client/src/services/fileDownloadService.ts로 브라우저 저장/다운로드 접근을 분리했다.
빌드npm run lint와 npm run build 기준으로 검증한다.

완료 기준

  • 프론트엔드 MVP가 백엔드 없이 독립적으로 동작한다.
  • Vite 빌드가 성공한다.
  • 저장/업로드 관련 코드가 이후 Next.js API로 교체 가능한 구조다.
  • 백엔드 개발을 시작하기 전 프론트엔드 기준점이 확정된다.
