2단계. 포토샵형 화면 레이아웃 구현

완료 포토샵처럼 도구와 패널이 고정된 작업형 화면을 만들었다.

목표

사용자가 첫 진입부터 중앙 캔버스, 좌측 도구, 우측 속성/목록 패널을 직관적으로 이해하게 한다.

구현 방향

상단 메뉴새 파일, 열기, 저장, 다운로드, 실행 취소, 다시 실행, 확대/축소 버튼을 배치한다.
좌측 도구 바선택, 이동, 펜, 브러시, 지우개, 채우기, 텍스트, 이미지 삽입 도구를 세로로 둔다.
중앙 작업 영역회색 작업 배경 위에 흰색 캔버스를 두고 스크롤과 확대/축소를 고려한다.
우측 패널속성, 업로드 이미지, 저장 목록, 캔버스 정보를 탭 또는 접이식 섹션으로 구성한다.
하단 상태 바현재 도구, 저장 상태, 확대 비율, 캔버스 크기를 표시한다.

주요 작업

  1. CSS Grid와 Flexbox로 전체 앱 프레임을 만들었다.
  2. 도구 버튼은 안정적인 크기의 아이콘 버튼 형태로 배치했다.
  3. 우측 패널에 속성, 업로드, 저장 목록, 캔버스 정보 탭을 만들었다.
  4. 모바일에서는 도구 바를 상단 전환형으로, 우측 패널을 하단 영역으로 내려 겹침을 줄였다.

완료 기준

  • 포토샵형 작업 구조가 화면에 명확히 보인다.
  • 중앙 캔버스 영역이 가장 큰 비중을 차지한다.
  • 주요 버튼과 패널이 작은 화면에서 겹치지 않는다.
