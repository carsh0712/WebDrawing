4단계. 기본 드로잉 도구 구현

완료 웹 드로잉에 필요한 기본 도구와 속성 제어를 구현했다.

목표

사용자가 좌측 도구 바와 우측 속성 패널만으로 기본적인 그림 작업을 할 수 있게 한다.

구현 방향

펜선명하고 일정한 굵기의 자유선을 그린다.
수묵화 브러시굵기와 투명도를 반영해 먹 번짐, 농담, 마른 붓 가장자리가 섞인 자유선을 그린다.
지우개브러시처럼 크기를 조절하며 기존 픽셀을 지운다.
색상기본 팔레트와 사용자 지정 색상을 함께 제공한다.
상태현재 선택 도구, 색상, 굵기, 투명도를 화면에 반영한다.

주요 작업

  1. 도구 상태 객체를 정의했다.
  2. 도구 버튼 클릭 시 활성 상태를 표시했다.
  3. 우측 속성 패널에서 색상, 굵기, 투명도를 변경할 수 있게 했다.
  4. 선 렌더링 시 현재 도구 설정을 적용했다.

완료 기준

  • 펜, 브러시, 지우개가 구분되어 동작한다.
  • 색상과 굵기 변경이 즉시 캔버스에 반영된다.
  • 현재 도구 상태를 사용자가 확인할 수 있다.
