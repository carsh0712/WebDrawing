8단계. 프론트엔드 로컬 저장 및 다운로드 완성

완료 React + Vite + TypeScript 프론트엔드 MVP에서 저장, 불러오기, 삭제, PNG 다운로드를 완성했다.

목표

백엔드 없이도 사용자가 브라우저에서 작업물을 저장하고 다시 열며, 완성 이미지를 PNG로 다운로드할 수 있게 한다.

구현 방향

저장소MVP는 브라우저 로컬 저장소를 사용한다. 이미지 데이터 용량이 커질 수 있으므로 IndexedDB를 우선 검토한다.
저장 데이터작업 이름, 저장 시각, 캔버스 크기, 캔버스 이미지, 썸네일, 업로드 이미지 참조 정보를 저장한다.
목록우측 패널에 저장 목록을 표시하고, 선택한 작업을 불러오거나 삭제한다.
다운로드현재 캔버스 내용을 PNG 파일로 변환해 다운로드한다.

주요 작업

  1. 프론트엔드 저장 데이터 타입을 정의했다.
  2. 저장, 덮어쓰기, 불러오기, 삭제 함수를 구현했다.
  3. 저장 목록 UI와 썸네일 표시를 구현했다.
  4. PNG 다운로드 버튼과 파일명 생성 규칙을 구현했다.
  5. 저장 실패, 빈 목록, 삭제 확인 상태를 처리했다.

완료 기준

  • 로그인 없이 작업을 저장하고 다시 불러올 수 있다.
  • 저장 목록에서 썸네일, 이름, 저장 시각을 확인할 수 있다.
  • PNG 다운로드 결과가 캔버스 표시와 일치한다.
  • 이 단계까지 백엔드 없이 프론트엔드 MVP 핵심 기능이 완성된다.
