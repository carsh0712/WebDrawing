3단계. 캔버스 엔진 및 포인터 입력 구현

완료 실제 드로잉이 이루어지는 Canvas 엔진과 입력 처리를 만들었다.

목표

마우스, 펜, 터치 입력으로 캔버스 위에 자연스럽게 선을 그릴 수 있게 한다.

구현 방향

렌더링HTML Canvas 2D Context를 사용한다.
입력pointerdown, pointermove, pointerup 이벤트로 통합 처리한다.
좌표캔버스 표시 크기와 실제 픽셀 크기 차이를 보정한다.
품질기기 픽셀 비율을 반영해 선이 흐릿하지 않도록 한다.

주요 작업

  1. 캔버스 초기 크기와 배경색을 설정했다.
  2. 포인터 좌표를 캔버스 내부 좌표로 변환했다.
  3. 드래그 중 연속 선을 그리는 로직을 만들었다.
  4. 입력이 끝나면 하나의 작업 단위로 기록할 수 있게 stroke 기록 구조를 준비했다.

완료 기준

  • 캔버스에 선이 끊김 없이 그려진다.
  • 마우스와 터치 입력이 같은 로직으로 동작한다.
  • 캔버스 크기 변경 또는 확대 상태에서도 좌표가 어긋나지 않는다.
