개발 계획서로 돌아가기

기타 단계 통합 안내

통합됨 기존 기타 단계였던 Next.js 백엔드, Vercel 배포, Supabase DB/Storage 연결 계획은 10단계 세부 계획서로 통합했다.

이전 범위

이 페이지는 원래 Vercel 배포, Next.js 백엔드, Supabase DB/Storage 연결, 인증 확장을 별도 기타 단계로 관리했다. 하지만 실제 작업 흐름상 10단계의 백엔드 확장 범위와 겹치므로, 상태 관리는 10단계에서만 진행한다.

현재 기준

  • 완료된 준비 작업과 대기 중인 실제 구현 작업은 docs/html/development-plan/step-10/index.html에서 관리한다.
  • 개발 환경은 Docker Postgres, 운영 환경은 Supabase를 기준으로 한다.
  • Vercel 배포 검증과 Supabase Auth/Storage 연결은 10단계의 대기 작업으로 남겨둔다.
