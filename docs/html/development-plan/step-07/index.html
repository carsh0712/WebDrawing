7단계. 업로드 이미지 캔버스 배치 구현

완료 업로드한 그림을 실제 캔버스 작업 대상으로 사용할 수 있게 했다.

목표

업로드 목록에서 선택한 이미지를 캔버스에 배치하고, 그 위에 드로잉할 수 있게 한다.

구현 방향

배치 방식선택 이미지의 원본 비율을 유지해 캔버스 중앙에 배치한다.
크기캔버스를 넘지 않는 기본 크기로 축소한다.
합성MVP에서는 배치 후 캔버스 픽셀로 합성하는 단순 방식을 우선한다.
이력이미지 배치도 Undo 대상 작업으로 기록한다.

주요 작업

  1. 선택 이미지를 Image 객체로 로드했다.
  2. 캔버스 기준 배치 좌표와 크기를 계산했다.
  3. Canvas 2D Context에 이미지를 그렸다.
  4. 이미지 배치 후 이력 스택에 상태를 저장했다.

완료 기준

  • 선택한 이미지가 캔버스에 보인다.
  • 이미지 위에 펜과 브러시로 그릴 수 있다.
  • 이미지 배치 작업을 되돌릴 수 있다.
