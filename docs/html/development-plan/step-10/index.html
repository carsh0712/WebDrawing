10단계. Next.js 백엔드 및 Supabase 연동 준비

대기 프론트엔드 MVP 이후 Next.js 백엔드 개발을 시작하기 위한 구조와 연결 지점을 정리한다.

목표

React + Vite 프론트엔드 MVP를 유지하면서, 서버 기능이 필요한 저장, 인증, 공유, DB 접근 기능을 Next.js 백엔드로 분리할 준비를 한다.

구현 방향

백엔드 스택Next.js 프레임워크를 사용해 API 라우트와 서버 전용 로직을 구현한다.
DBSupabase Database를 사용해 사용자, 작업물, 업로드 이미지, 공유 링크 정보를 저장한다.
파일Supabase Storage를 사용해 업로드 이미지와 썸네일 파일 저장을 검토한다.
프론트 연결기존 프론트엔드의 저장 서비스 인터페이스를 Next.js API 호출로 교체할 수 있게 한다.

주요 작업

  1. Next.js 백엔드 프로젝트 위치와 실행 방식을 결정한다.
  2. API 엔드포인트 초안을 정의한다.
  3. Supabase 환경 변수와 서버 전용 키 사용 정책을 정리한다.
  4. 프론트엔드에서 호출할 저장, 조회, 업로드 API 계약을 작성한다.
  5. Vercel 배포 구조를 프론트엔드와 백엔드 관점에서 결정한다.

완료 기준

  • Next.js 백엔드 개발 범위가 확정된다.
  • 프론트엔드 MVP와 백엔드 API의 연결 지점이 명확하다.
  • Supabase DB/Storage 설계 초안이 준비된다.
  • Vercel 배포 전략을 선택할 수 있다.
