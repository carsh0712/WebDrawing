1단계. React + Vite + TypeScript 프론트엔드 구조 생성

완료 웹 드로잉 MVP를 개발할 React + Vite + TypeScript 기반 프론트엔드 구조를 만들었다.

목표

문서와 실제 앱 코드를 분리하고, Vite 개발 서버에서 빠르게 실행 가능한 프론트엔드 MVP 개발 기반을 준비한다.

구현 방향

앱 위치src/ 아래에 React 컴포넌트, 훅, 서비스, 타입, 스타일 파일을 둔다.
문서 위치현재 HTML 문서는 docs/html/ 아래에서 유지한다.
프론트엔드 스택React + Vite + TypeScript로 개발한다.
백엔드 분리Next.js 백엔드는 프론트엔드 MVP 완성 이후 별도 단계에서 개발한다.

주요 작업

  1. Vite React TypeScript 프로젝트를 생성했다.
  2. 전역 스타일 파일과 앱 전용 TypeScript 파일을 분리했다.
  3. 캔버스, 도구 바, 패널, 저장소, 업로드 기능을 위한 폴더 구조를 만들었다.
  4. 업로드 이미지, 아이콘, 샘플 데이터가 들어갈 에셋 폴더를 준비했다.
  5. 앱 문서와 개발 계획서 링크를 README에서 찾을 수 있게 했다.

완료 기준

  • Vite 개발 서버에서 React 앱 진입 화면이 열린다.
  • TypeScript, CSS, React 컴포넌트가 정상 로드된다.
  • 이후 단계에서 레이아웃과 캔버스 코드를 추가할 위치가 명확하다.
